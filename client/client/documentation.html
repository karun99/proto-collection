1. Project Overview

Royal Mutton Hub is a fully static, no-backend website for a Vijayawada-based B2B mutton distributor. It serves hotels, restaurants, caterers, mess, and retail chains across Krishna, NTR, and Guntur districts with same-day delivery. The brand emphasizes fresh, pure, tender mutton delivered daily with a "No Refrigeration — Only Freshness" USP.

The project includes an AI-powered chatbot (via OpenRouter), a rich recipe database (RecipeDB) with chef-credited recipes and user submissions, lead capture, SEO-optimized static pages, a full admin dashboard, anti-bot protections, meeting scheduling, and password management — all running client-side with localStorage-based persistence.

Developed by: Guiding Key  |  Client: Royal Mutton Hub, Vijayawada

Key Differentiators

  • No refrigeration — fresh mutton delivered daily
  • Indigenous Vijayawada brand since 2005, rooted in Andhra Pradesh culinary heritage
  • B2B-focused: dedicated service for hotels, restaurants, caterers, mess, retail chains
  • Same-day delivery across Krishna, NTR & Guntur districts
  • All prices in INR for budget-friendly positioning

5.6 Security Features

  • AES-256-GCM encryption for API keys, backups, and sensitive data
  • DevTools detector: dimension delta check every 2s; blanks page if detected
  • Right-click disabled, text selection disabled, copy/cut/drag blocked
  • Keyboard shortcut blocking: Ctrl+C/U/S/P/I/J/Y/A/F/E/H, F12
  • Email obfuscation: address split into JS variables, decoded at runtime
  • Input sanitization on all user-submitted data
  • Rate limiting on recipe submissions (3/hour)
  • CSP headers via meta tag, Netlify TOML, and Vercel JSON

7. Configuration Guide

7.1 API Key Setup

  1. Open admin dashboard (/admin.html) in your browser
  2. Login with default password: admin123
  3. Navigate to API Keys tab
  4. Paste your OpenRouter API key (get one at https://openrouter.ai/keys)
  5. Click Save
  6. Select a model from the dropdown (e.g., openrouter/free, google/gemini-2.5-pro-exp:free)
  7. Click Test API Key to verify

7.2 Changing Admin Password

  1. Go to Password tab in admin dashboard
  2. Enter current password (default: admin123)
  3. Enter new password (minimum 6 characters)
  4. Confirm new password
  5. Click Change Password
  6. The next login will require the new password

7.3 API Key Storage Chain

  1. Admin dashboard saves API key as encrypted copy (rmh_admin_apiKey) + plaintext copy (rmh_bot_apikey)
  2. utils.js (sync, loads before embed.js) reads rmh_bot_apikey and sets window.__RMH.API_KEY
  3. embed.js uses window.__RMH.API_KEY for OpenRouter API calls, with hardcoded fallback

7.4 Theme Configuration

In the Theming tab:

  • Dark/Light mode toggle
  • Accent color picker (default: #d4a017 — royal gold)
  • Font selector (from Google Fonts library)
  • Border radius slider (0-30px, default: 14px)
  • 5 preset themes: Royal (default), Midnight, Emerald, Ruby, Ocean

8. Deployment Guide

  1. Push the project folder to a Git repository (GitHub/GitLab/Bitbucket)
  2. Go to https://app.netlify.com → Add new site → Import from Git

10. User Manual — Admin Operations

This section provides step-by-step instructions for all admin operations. The admin dashboard is accessible at /admin.html and requires password authentication.

10.1 Logging In

  1. Navigate to https://your-site.com/admin.html in your browser
  2. Enter your admin password (default: admin123)
  3. Click Unlock Dashboard
  4. On first login, change the default password immediately via the Password tab

10.2 Managing API Key

  1. After logging in, click API Keys in the sidebar
  2. Paste your OpenRouter API key into the API Key field
  3. (Optional) Select a different AI model from the dropdown
  4. Click Save API Key — a success toast will confirm
  5. Click Test API Key to verify the key works
  6. Use the eye icon to toggle key visibility
  7. To rotate: click Rotate, confirm, then enter a new key

10.3 Changing Password

  1. Click Password in the sidebar
  2. Enter your current password
  3. Enter your new password (minimum 6 characters)
  4. Re-enter the new password to confirm
  5. Click Change Password
  6. A success toast confirms the change
  7. The current password hash is displayed for reference

10.4 Customizing Branding

  1. Click Branding in the sidebar
  2. Edit any field: Business Name, Tagline (English), Tagline (Telugu), Address (English), Address (Telugu), Phone, WhatsApp, Email
  3. Each field auto-saves when you type (debounced)
  4. Mutton Cuts: type a cut name and click Add Cut to add; click the X icon next to a cut to remove it
  5. Custom CSS: write CSS rules in the textarea — applied site-wide
  6. Changes reflect immediately on the dashboard

10.5 Applying Themes

  1. Click Theming in the sidebar
  2. Toggle Dark/Light mode using the switch
  3. Pick an accent color using the color picker
  4. Select a font from the dropdown (loaded from Google Fonts)
  5. Adjust border radius using the slider (0-30px)
  6. Or click one of the 5 preset theme buttons for instant styling
  7. All changes preview in real-time

10.6 Managing Recipes (RecipeDB CRUD)

Viewing & Searching

  1. Click RecipeDB in the sidebar
  2. All recipes are displayed in a table with columns: Name, Author, Type (seed/chef/user), Diet, Cuisine
  3. Use the search bar to filter by name, author, or cuisine
  4. Use the dropdown to filter by type: All, User Recipes, or Chef Recipes

Adding a Recipe

  1. Click Add Recipe button above the table
  2. Fill in the recipe form: name, author, category, cuisine, meal type, diet, budget, cost estimate, difficulty, prep time, cook time, servings, image (emoji), dietary restrictions
  3. Enter ingredients (one per line)
  4. Enter steps (one per line)
  5. Enter tips (one per line)
  6. Enter equipment (comma-separated)
  7. Click Save to add the recipe

Editing a Recipe

  1. Find the recipe in the table
  2. Click the edit (pencil) icon in the Actions column
  3. Modify any fields in the form that appears
  4. Click Save Changes
  5. Note: Chef recipes are view-only and cannot be edited

Deleting a Recipe

  1. Click the delete (trash) icon next to a recipe
  2. Confirm the deletion in the dialog
  3. Only user recipes can be deleted individually
  4. To delete all user recipes: use Clear User Recipes in Data Management → Danger Zone

10.7 Managing Meetings

  1. Click Meetings in the sidebar
  2. All meeting requests appear in a table with: Name, Phone, Email, Date, Time, Notes, Status, Actions
  3. Use the search bar to find by name, phone, or email
  4. Use the status filter dropdown to view: All, Pending, Confirmed, Completed, Cancelled
  5. Actions per meeting:
  • Green checkmark → Confirm (moves from pending to confirmed)
  • Double checkmark → Complete (moves from confirmed to completed)
  • Red X → Cancel (cancels the meeting)
  • Undo arrow → Reopen (moves from cancelled back to pending)

Status Flow: pending → confirmed → completed (happy path) | pending/confirmed → cancelled (rejection) | cancelled → pending (reopen)

10.8 Data Management

Encrypted Backup

  1. Click Data Management in the sidebar
  2. Under Export All Data, enter your admin password
  3. Click Export Encrypted Backup — downloads a .rmhbak file
  4. To restore: select the .rmhbak file, enter the same password used during export
  5. Click Import & Restore — all data is restored. Reload the page.

Local Snapshots

  1. Click Snapshot Now to save a plain JSON summary (no API key)
  2. Last 5 snapshots appear below the button with timestamp and summary
  3. Maximum 20 snapshots retained (oldest auto-removed)

Export / Import CSV & JSON

Located in the Export / Import (CSV & JSON) card below the main data management grid.

Exporting:

  • Recipes: Click JSON or CSV — downloads all user recipes
  • Meetings: Click JSON or CSV — downloads all meeting requests
  • Leads: Click JSON or CSV — downloads all captured leads
  • Reviews & Ratings: Click JSON for text reviews, Ratings for appreciation data

Importing (Recipes & Meetings):

  • Click the JSON or CSV button under Import for the data type
  • Select the file from your computer
  • Data is appended to existing records (no duplicates removed)
  • A toast confirms how many records were imported
  • CSV format: first row must be headers matching field names. Arrays (ingredients, steps, etc.) use semicolons as separators.
Danger Zone — These actions cannot be undone:
- Clear User Recipes — deletes all user-submitted recipes (seed & chef preserved)
- Reset Analytics — clears all page views, API calls, and lead data
- Factory Reset All Data — deletes EVERYTHING (passwords, API keys, all recipes, analytics, backups, themes, branding). Page reloads automatically. Two confirmation dialogs protect against accidental use.

10.9 Monitoring API Usage

  1. Click API Usage in the sidebar
  2. Four stat cards show: Total Page Views, API Calls, Total Leads, Avg Views/Day
  3. Leads table: Name, Source (chatbot/form with color-coded badge), Date, Recipe
  4. API Calls table: Date, Model name, Query preview (first 80 characters)

10.10 Chatbot Operations (User-Facing)

The chatbot is visible on the main site (bottom-right widget). Users can:

  • Chat Tab — Ask questions about mutton supply, pricing, recipes. AI-powered with canned fallback.
  • Quote Tab — Request a B2B quote: name, phone, email, quantity, notes.
  • Order Tab — Place an order: name, phone, email, cut selection, quantity, delivery date.
  • Meeting Tab — Schedule a B2B consultation: name, phone, email, preferred date, time, notes. Saves to rmh_meetings with pending status.
  • Policy Tab — View business policies: delivery, payment, quality assurance, cancellation.

10.11 Recipe Features (User-Facing)

  • Browse recipes in the grid — filter by search, diet, budget, cuisine, meal type, category
  • Click a recipe card to open the modal with full details
  • Submit a recipe via the Submit Your Recipe form — rate-limited to 3/hour
  • Rate recipes (1-5 stars) and mark I Cooked This!
  • Post text reviews with your name and feedback
  • Share recipes via WhatsApp, Facebook, X, Telegram, Email, Copy Link, or open the full RecipeDB page
  • Filter by dietary restrictions: gluten-free, dairy-free, nut-free, egg-free, vegan

12. Build Scripts

12.1 generate-recipes.js

Parses both utils.js (BUSINESS.recipes) and chef-recipes.js (C.CHEF_RECIPES) arrays, then generates 22 static HTML files in the RecipeDB/ folder with per-recipe JSON-LD, Open Graph tags, chef badges, share buttons, and prev/next navigation.

node generate-recipes.js

Must be re-run after any recipe changes (add/edit/delete).

12.2 fetch-commodity-prices.js

Node.js build script that fetches live mandi prices from the data.gov.in API. Includes 14 commodity defaults in INR as fallback.

node fetch-commodity-prices.js --output prices.json

12.3 generate_doc.py

Python script that generates the Word documentation file. Requires python-docx.

pip install python-docx
python generate_doc.py
