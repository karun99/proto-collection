About PromptPro Arena

PromptPro Challenge Arena is a sophisticated learning platform designed to master the art of Prompt Engineering. It combines competitive challenges, an extensive prompt library, and an AI-powered mentorship system.

🛡️ Encryption & Security Standards

The application employs a multi-layered security architecture to ensure data integrity and privacy, utilizing industry-standard cryptographic primitives:

Standard: AES-256-GCM (Galois/Counter Mode)
Key Derivation: PBKDF2 with SHA-256
Iterations: 120,000
Salt: Project-specific deterministic salt

All sensitive data stored in the database files (students.json, prompts.json, packs.json) is encrypted at rest. The encryption ensures that only authorized entities with the project's master key can decrypt the contents, preventing unauthorized access to student records and proprietary prompt libraries.

🏗️ System Architecture

  • Serverless Backend: Deployed on Vercel with Node.js serverless functions for high availability.
  • JSON-based Persistence: Uses a structured file-based database system for rapid access and easy portability.
  • Hybrid AI Orchestration: Integrates multiple LLM providers (OpenRouter, NVIDIA) via a master-student key fallback system.
  • Real-time Evaluation: Automated prompt scoring based on clarity, structure, and alignment with expected outcomes.
